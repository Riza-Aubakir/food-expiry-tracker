Азық-түлік өнімдерінің жарамдылық мерзімін бақылау жүйесі

Жобаның мақсаты
Азық-түлік өнімдерінің жарамдылық мерзімін бақылауға, өнімдерді басқаруға және мерзімі өтіп кеткен өнімдерді анықтауға арналған веб-қосымша.

Қолданылған технологиялар
PHP
MySQL
HTML
CSS
XAMPP
Git және GitHub

Жоба мүмкіндіктері
Пайдаланушыны тіркеу
Жүйеге кіру және шығу
Өнімдерді қосу
Өнімдерді қарау, өзгерту және өшіру
Өнімдерді іздеу
Жарамдылық мерзімінің күйін көрсету
Өнімдерді санаттар бойынша ұйымдастыру

Жоба құрылымы
php/index.php — басты бет
php/products.php — өнімдерді басқару
php/register.php — тіркелу
php/login.php — жүйеге кіру
php/logout.php — жүйеден шығу
php/db.php — дерекқорға қосылу
css/style.css — сайттың дизайны
Орнату
XAMPP бағдарламасын орнату.
Apache және MySQL серверлерін іске қосу.
Жоба папкасын C:\xampp\htdocs\food-expiry-tracker ішіне орналастыру.
phpMyAdmin арқылы food_expiry_db дерекқорын жасау.
users, categories, products кестелерін құру.

Браузерде http://localhost/food-expiry-tracker/php/index.php мекенжайын ашу.
